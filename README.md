# PMT FAQ Bot

This package runs `pmt_faq_bot` on `10.20.3.17` while reusing LLM, embedding,
rerank, and Qdrant services on `10.203.97.4` (`xe9680`).

## Services

- `pmt_faq_bot`: FastAPI OpenAI-compatible RAG API on container port `8088`.
- `pmt_faq_bot_ingest`: one-shot ingest job for the `PMT-FAQ` Qdrant collection.
- `pmt_faq_bot_image_process`: one-shot OCR/VLM image metadata job.
- `open-webui`: optional local WebUI on VM port `3000`.

The source for the bot image is `pmt_faq_bot/`. The old `models/rag-ingest`
tree is intentionally not used by this PMT package.

## Data Layout

Set `EXPORT_DIR` to a complete Confluence export package:

```text
export/
  documents/
  assets/
  manifest.jsonl
  image_manifest.jsonl
  processed_image_manifest.jsonl
```

`processed_image_manifest.jsonl` is generated by the image processing job.
Unavailable images are skipped; downloaded images can become image chunks and
can be returned in answers as Markdown images.

Do not point `EXPORT_DIR` at `documents/` alone. If your export is under a
subdirectory such as `./confluence_documents/faq-zh-721033694-images-20260519`,
set `EXPORT_DIR` to that subdirectory.

## Configure

```bash
cd PMT-FAQ-Bot
cp app-vm-3-17.env.example .env
```

Keep these values aligned with the target deployment:

```bash
QDRANT_URL=http://10.203.97.4:6333
EMBEDDING_URL=http://10.203.97.4:8001
RERANK_URL=http://10.203.97.4:8002
LLM_URL=http://10.203.97.4:8000
COLLECTION_NAME=PMT-FAQ
RAG_MODEL_NAME=pmt_faq_bot
EXPORT_DIR=./export
```

If users open WebUI from another machine, change `RAG_ASSET_BASE_URL` from
`127.0.0.1` to the reachable VM host/IP.

## Build And Run

```bash
docker compose --env-file .env build pmt_faq_bot
docker compose --env-file .env up -d pmt_faq_bot open-webui
```

Process images before ingesting documents:

```bash
docker compose --env-file .env --profile image-processing run --rm pmt_faq_bot_image_process
docker compose --env-file .env --profile ingest run --rm pmt_faq_bot_ingest
```

The ingest job creates or updates the Qdrant collection named `PMT-FAQ`.
